# Changelog

All notable changes to Bran will be documented in this file.

## 0.3.0 - 2026-08-13

- Added the `bran-rewrite` child skill for authorized screenplay and fiction adaptation before human Taste review.
- Added PDF, FDX, Fountain, text, JSON, ScriptBreak, and LangExtract ingestion or normalization paths.
- Added evidence-backed extraction, abstract Story DNA, clean-room brief, independent rewrite-draft, and Taste-review handoff contracts.
- Added machine-enforced rights gating, source-span hashes, analyst/writer access separation, source-term and long-phrase risk checks, and immutable stage hashes.
- Added automatic `BranInputBundle` generation, deterministic Bran compilation, compile audit, and an `awaiting-taste-review` handoff.
- Added an original end-to-end English female-led thriller fixture and rewrite regression suite.
- Added deterministic `export-hodor`, resumable `apply-hodor`, and `verify-hodor` commands with stable node, edge, variable, script, revision, and validation receipt contracts.
- Added `diff-hodor` and revision-guarded `sync-hodor` for stable-key incremental branch, script, variable, entry, and ending updates.
- Added Bran-to-Hodor condition expansion, safe variable naming, typed effect checks, settlement hubs, explicit endings, deterministic canvas positions, and complete node-script rendering.
- Added entry-scene reachability and explicit branch-target validation to the core compiler.
- Added DOCX ingestion, pasted-source standard input, and interactive rewrite designs that compile directly into Hodor targets.

### Upgrade notes

- Existing `0.2.0` `BranInputBundle` inputs remain supported; interactive Hodor fields are additive.
- Install both `bran` and `bran-rewrite`, then restart Codex so the new child skill is discovered.
- Sources marked `unknown` or `internal-research` remain analysis-only and cannot enter brief sealing or draft generation.
- Hodor apply and sync commands require an explicit token environment variable and a matching import receipt; they stop on revision or binding drift.

## 0.2.0 - 2026-07-18

- Added the zero-dependency `bran compile`, `bran audit`, and `bran settle` CLI.
- Added schemas for `SourceEvent`, `BranInputBundle`, `NarrativePackage`, `ProductionRequest`, and the runtime contract.
- Replaced story-specific settlement and scene checks with a package-driven auditor.
- Added machine-readable derived-state expressions and generic prioritized settlement evaluation.
- Added compiler and audit receipts with deterministic artifact hashes and tamper detection.
- Added hash-bound staged author reviews and automatic `compiled` to `reviewed` lifecycle promotion.
- Added stable-ID package diffs and immutable lineage guidance for revision, fork, and rollback flows.
- Added an original three-scene, two-recipe fixture and automated core regression tests.
- Defined the boundary between Bran narrative compilation, downstream material production, UYI runtime state, and relationship-memory candidates.
- Legacy packages whose derived fields contain prose `formula` values only must add machine-readable `expression` values before the generic auditor can recompute settlement.

## 0.1.0 - 2026-07-16

- Published the initial Bran Agent Skill and Codex plugin wrapper.
- Added artifact and quality-gate contracts for executable branching-story packages.
- Added an independent Node.js auditor for state paths, replay mechanics, evidence decisions, Agent information gain, settlement consistency, trace coverage, dominance, carryover classes, and quality-receipt freshness.
- Added a repository marketplace for Codex installation.
